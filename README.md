# iPog SEO Landing Site

Optimized landing site for iPog — custom software development, AI automation, speech analytics, and MVP solutions.

## Pages

- **Homepage** (`/`) — Main marketing site with core service overview
- **Custom Software Development** (`/services/custom-software.html`) — Enterprise web apps, APIs, cloud infrastructure
- **Speech Analytics** (`/services/speech-analytics.html`) — Conversation intelligence, meeting transcription, sentiment analysis
- **AI Automation** (`/services/ai-automation.html`) — LLM-powered workflows, business process automation
- **MVP Development** (`/services/mvp-development.html`) — Fast startup prototypes in 4–8 weeks

## SEO Features

- ✅ Full HTML5 semantic markup
- ✅ Rich schema.org structured data (JSON-LD)
- ✅ Optimized meta tags and descriptions
- ✅ Mobile-responsive design
- ✅ sitemap.xml with all pages
- ✅ robots.txt for search engines
- ✅ Canonical URLs and hreflang tags
- ✅ OpenGraph and Twitter Card tags
- ✅ 404 error page
